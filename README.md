# ⚡ Flux Flasher (v3.9.9 BETA)

**Flux Flasher** is a sleek desktop application for flashing ESP32-S3 and other devices. Built for those who value convenience, speed, and cyberpunk aesthetics.

![Version](https://img.shields.io/badge/version-3.9.9_BETA-00f0ff)
![Platform](https://img.shields.io/badge/platform-Windows-blue)
![License](https://img.shields.io/badge/license-MIT-green)

## 🚀 What's New in 3.9.9 BETA

*   **Fixed Chip Dropdown**: The menu no longer overlaps the "ONLINE" button and scrolls correctly.
*   **New Firmwares**: Added support for ESP32-C5, ESP32-C5-TFT, Madara-board, and Flipper Oled.
*   **Smart Installer**: The app now automatically checks for Python and esptool and installs them if necessary.
*   **Stability**: Fixed minor UI bugs and improved COM-port handling.

## 📦 Features

*   **Stylish Interface**: Cyberpunk-style terminal design with dark/light theme support.
*   **Online Catalog**: Automatic loading of the latest firmwares (Bruce, Marauder, NEMO, etc.) directly from the repository.
*   **Device Support**: FLUX, T-Embed (CC1101/Base), M5StickC Plus 2, M5StickC S3, Cardputer Adv, and an "OTHER" mode for ESP32-S3, C5, and other chips.
*   **Convenience**: Drag & Drop files, COM-port selection, and real-time flashing progress display.
*   **Localization**: Russian and English language support.

## 📥 Installation

1.  Download the latest installer from the Releases section.
2.  Run FluxFlasher_Setup_v3.9.9_beta.exe.
3.  Follow the installer instructions. The program will automatically install the required dependencies (Python, esptool).
4.  Launch Flux Flasher from your desktop.

## 🛠 Building from Source

1.  Install Node.js.

2.  Clone the repository:
    ```bash
    git clone https://github.com/Flux-developer42/Flux-Flasher.git
    cd Flux-Flasher

4.  Install dependencies:
    ```bash
    npm install

5.  Run the app in development mode:
    ```bash
    npm start

6.  Build the .exe file:
    ```bash
    npm run build
